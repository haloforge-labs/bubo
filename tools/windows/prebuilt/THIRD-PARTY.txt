Third-party dependencies in the Bubo Windows archive
===================================================

AMD runtime files and model weights are acquired separately by bubo prepare.
They are not included in this archive. Preparation prints the applicable
runtime disclosure and saves the complete runtime notice bundle in licenses\
beside bubo.exe. Model weights are subject to their model licence, not MIT.

The archive includes these unmodified non-AMD dependencies:
  OpenSSL libcrypto - Apache-2.0
  curl libcurl - curl licence
  ICU icudt78, icuin78, icuuc78 - Unicode License V3
  libpng libpng16 - PNG Reference Library License
  libjpeg-turbo jpeg62 - IJG / BSD-3-Clause
  WebP libwebp and libsharpyuv - BSD-3-Clause (licenses/libwebp.txt)
  zlib z.dll - zlib licence (licenses/zlib.txt)
  Microsoft Visual C++ msvcp140/vcruntime140 - Microsoft redistributable terms

Bubo's source licence is in LICENSE. Complete dependency/source notices and
redistribution provenance remain subject to the release notice review.
