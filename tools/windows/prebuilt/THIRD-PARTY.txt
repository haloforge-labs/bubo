Third-party dependencies in the Bubo Windows archive
===================================================

AMD runtime files and model weights are acquired separately by bubo prepare.
They are not included in this archive. Preparation prints the applicable
runtime disclosure and saves the complete runtime notice bundle in licenses\
beside bubo.exe. Model weights are subject to their model licence, not MIT.

The archive includes these unmodified non-AMD dependencies:
  OpenSSL libcrypto - Apache-2.0
  curl libcurl - curl licence
  ICU icudt78, icuin78, icuuc78 - Unicode License V3
  libpng libpng16 - PNG Reference Library License
  libjpeg-turbo jpeg62 - IJG / BSD-3-Clause
  WebP libwebp and libsharpyuv - BSD-3-Clause (licenses/libwebp.txt)
  zlib z.dll - zlib licence (licenses/zlib.txt)

NPU prefill kernel files in tools\npu (xclbin as built by the fork, with sources):
  from mikealanni/gufo (MIT), derived from AMD mlir-aie examples,
  Apache-2.0 WITH LLVM-exception (licenses/mlir-aie-Apache-2.0-LLVM-exception.txt)
Strata grouped decode expert kernel (adapted from Niko1221/Strata) - MIT (licenses/strata-MIT.txt)
GSQHalo.cpp / ggml routed IQ/Q2 expert slice decoders and WMMA staging - MIT,
  Copyright (c) 2023-2026 The ggml authors (licenses/gsqhalo-MIT.txt)

Prerequisite: Microsoft VC++ v14 x64 Redistributable (not shipped).
Install it separately from Microsoft's official installer:
  https://aka.ms/vs/17/release/vc_redist.x64.exe
Bubo does not download it or include Microsoft CRT binaries in the archive.

Bubo's source licence is in LICENSE. Complete dependency/source notices and
redistribution provenance remain subject to the release notice review.

GUI and updater
---------------
The desktop package's generated inventory is licenses/gui/THIRD-PARTY-GUI.md
(source: docs/release/THIRD-PARTY-GUI.md). Complete GUI and updater dependency
licence texts accompany that inventory.
